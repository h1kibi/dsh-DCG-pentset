# 既有作业档案的消费（engagement-archive）

## 适用场景
- **每次进入作业会话的第一步**，尤其是：回环后的新一轮、接手他人做过的目标、范围被修订过之后。
- 目标只有一个：**在动手之前，把"上一轮已知什么"变成可引用的四段事实**（结论 / 线索 / 排除 / 时效）。
- 这是"零成本动作"：读档案不碰目标、不进范围闸门、不产生动作类别——**先读，再决定要不要打**。

## 前提与边界
- 档案挂在**人类配置的只读锚点**上（本部署是 `/mnt/engagement`，只读）。**实际生效的根以 `pentest_workdir op=list` 返回的 `roots` 为准**（配置可能不同、`/work` 还会跟随本会话的工作目录）。
- 档案是**自由文本**（没有 schema、没有字段保证）：报告、清单、交接材料、脚本片段都可能混在一起 ⇒ 必须按"时间 + 四段"去读，不能按字段去读。
- **档案里的结论是"上一轮的当时判断"，不是本轮已验证的事实**：引用它要带来源与时间；与本轮实测冲突时**以本轮实测为准**并把差异写下来。
- 凭据、证书、令牌类内容**默认已过期**（实测：前序报告里的证书早已轮换）。要按"对目标的新动作"处理，并走对应动作类别的放行。
- 本轮作业的**授权边界以本会话的范围裁决为准**，档案里的目标清单只是线索——范围没变不代表可以照打。
- 沙箱侧读文件是 `local_only`（容器没有网、不做范围裁决，账本单列 `local_processing`）；**读档案不需要目标**。

## 步骤

> **优先用 `pentest_workdir`**（宿主侧，op=list/read/search/append）：它**不经过范围闸门**——
> 空范围作业（范围版本 0）里连 `ls /work` 都跑不了，而读作业资料与目标无关。
> 下面每步都给出**沙箱侧等价命令**（写进 `pentest_exec` 时带 `local_only=true`），便于把原文落进证据。

### 1. 确认挂载根与概览（先看有没有东西可读）
```bash
ls -la /mnt/engagement/ 2>&1 | head -40
```
期望：列出顶层目录/文件（常见形态：`reports/`、`notes/`、`handoff-*.md`、`清单.md`，或直接就是几份 `.md`）。
判据：能看到至少一份文件名里带日期或阶段名的文本文件才继续；**目录不存在或全空**就明确写"本轮无既有档案"，不要向人类要一份不存在的东西。

### 2. 找"最近动过"的那几份（别从最早那份开始读）
```bash
find /mnt/engagement -type f -printf '%TY-%Tm-%Td %TH:%TM  %s  %p\n' 2>/dev/null | sort -r | head -20
```
期望：按修改时间倒序的文件清单（带日期、大小、路径）。
判据：**先读最近动过的 2–3 份**（交接材料/最终报告通常就是它）；更早的文件只在需要追线索时再翻——档案目录往往几十份，全读等于不读。

### 3. 结构化检索四段关键词（省上下文的关键一步）
```bash
grep -rn -E '结论|线索|排除|未决|遗留|已轮换|已过期|范围版本' /mnt/engagement 2>/dev/null | head -60
```
期望：命中行形如 `handoff-2.md:14: 结论：…`、`notes/证书.md:3: 已轮换…`。
判据：**命中文件按出现频次排优先级**（`pentest_workdir op=search` 还会直接给出 `files` 列表：路径 + 修改时间 + 命中行数，新的在前）。一条都没命中 ⇒ 档案可能只是日志/原始输出，按第 2 步的时间序读最近那份的**开头与结尾**（开头写目标、结尾写结论）。

### 4. 按四段把结论抽出来（读到能复述为止）
```bash
sed -n '1,40p'  /mnt/engagement/<最近那份>.md
grep -n -A 8 -E '^#{1,3} *(结论|线索|排除|时效)' /mnt/engagement/<最近那份>.md | head -60
```
期望：能填出四行——**结论**（上一轮确证了什么）、**线索**（未证实的怀疑）、**排除**（试过且否掉的，含否掉的方式）、**时效**（证书/凭据/版本/范围是否已变）。
判据：四段里**缺哪段就明确写"档案未提供"**；把"线索"当成"结论"是这份档案最贵的误读（一条未证实的怀疑被当成事实引用，会把整条证据链污染）。

### 5. 时效核验（最容易被跳过、代价最大的一步）
```bash
# 证书类：看有效期与来源（示例：档案里提到的 PEM 文件）
openssl x509 -in /mnt/engagement/<某证书>.pem -noout -subject -dates 2>&1 | head -5
# 版本/范围类：档案里写的范围版本与本会话的范围（见控制台/范围卡）对不上时，以本会话为准
grep -rn -iE '范围版本|scope version|证书|凭据|token' /mnt/engagement 2>/dev/null | head -30
```
期望：拿到证书的 `notBefore/notAfter`，或档案里声明的范围版本号。
判据：`notAfter` 早于今天 ⇒ 记"已过期，不可复用"；范围版本与本会话不一致 ⇒ 记"档案范围已失效，需按本会话范围重做"（这一步实测抓到过"前序报告里的证书已轮换"）。

### 6. 把摘要写回本轮作业（让下一轮/下一个人少走一遍）
```bash
mkdir -p /work/notes && cat >> /work/notes/archive-read.md <<'EOF'
档案消费（本轮）：
- 读了：<文件名 + 日期>
- 结论（引用）：<一句 + 来源文件:行>
- 线索（未证实）：<…>
- 排除（别重复做）：<…>
- 时效：<证书/凭据/范围版本>
EOF
```
期望：`/work/notes/archive-read.md` 落盘（`/work` 是可写根；`/mnt/engagement` 只读，写它会被拒绝）。
判据：四段齐全且**每条都带来源**（文件名 + 行号或日期）；走结构化通道时用 `pentest_workdir op=append` 追加到同一份台账（`op=write` 会覆盖，补一行用 `append`）。

## 判读与去噪
- **时间优先于目录结构**：档案的权威顺序是"最近改动 > 目录层级深"。先看 `find -printf '%T@'` 的排序，再决定读什么。
- **原始输出 ≠ 结论**：扫描结果、命令回显、日志片段只是素材；只有"结论/线索/排除"三段是能直接引用的。
- **排除项与结论同等值钱**：`排除：/admin 不是入口（401 且无绕过）` 能直接省掉一整轮动作——读到就写进本轮台账。
- **线索要降级引用**：写"档案里的线索（未证实）"而不是"已知漏洞"。**未证实的东西被当事实引用**是本类档案最常见的污染。
- **口径漂移**：上一轮用的字典/工具版本/范围版本可能与本轮不同，命中率差异要归因到口径而不是"目标变了"。
- **只读根不是不能写**：`pentest_workdir` 对只读根写会明确回 `read_only`；那是设计，不是故障——把笔记写到 `/work`（可写根）。

## 常见失败
| 现象 | 真实原因 | 处置 |
|---|---|---|
| `pentest_exec` 报 `out_of_scope`（连 `ls /work` 都跑不了） | 该命令要求声明已授权目标，空范围作业里没有目标可声明 | 读作业资料用 `pentest_workdir`（宿主侧、不经范围闸门）；确需在容器里跑命令时用 `local_only=true` |
| 档案目录几十上百份，逐份读把上下文吃光 | 缺少"先排序再读"的一步 | 第 2 步按 mtime 倒序只取最近 2–3 份；第 3 步用关键词检索缩小范围（`op=search` 直接给命中文件清单） |
| 引用了档案里的"已验证"结论，本轮实测却相反 | 档案里的是**当时**判断；目标可能已变（证书轮换、服务下线、配置改动） | 第 5 步做时效核验；引用带来源与时间；冲突以本轮实测为准并写下差异 |
| 把档案里的凭据拿去登录 | 凭据默认已过期，且这是**对目标的新动作** | 不用档案里的凭据直接动作；需要时向人类申请并走对应动作类别的放行 |
| 写 `/mnt/engagement` 被拒（`read_only`） | 那是只读锚点（有意为之） | 笔记写到 `/work`（可写根）；`op=list` 的 `roots` 里带"只读/读写"标注 |
| 怀疑读到的目录不属于本作业 | 挂载根由人类配置，配错就会读到别的作业 | **停止写操作**并告知人类；先用 `op=list .` 核对 `roots` 再继续 |

## 不做的事
- **不把档案当授权**：档案里的目标清单不构成本轮范围；范围只以本会话的裁决为准。
- **不在只读根上写**：档案是别人（或上一轮的自己）的证据，改动它等于篡改历史。
- **不把未证实的线索当结论写进报告**：要么标 `[未证实]` 并给来源，要么本轮自己验证。
- **不用档案里的凭据/证书直接动作**：过期是常态，且那是对目标的新动作，要按类别走放行。
- **不在开工前跳过这一步**：跳过它换来的不是速度，是重复劳动和"把过期的当现状"。

## 产出（交给下一步）
- **档案消费台账**（本轮）：读了哪几份（文件 + 时间）、四段摘要（结论/线索/排除/时效）、每条带来源。
- **别重复做的事**清单：档案里已排除的路径/手法（含否掉方式），直接引用即可。
- **时效结论**：证书/凭据/范围版本中已失效的项，明确写"不可复用"。
- **待验证线索**：档案里的怀疑项 + 它当时的证据等级（未证实/部分证实），交给本轮动手时优先验证。
